// PIPELINE EXECUTION ARCHITECTURE

How The Autonomous Production Engine Works

STAGE 01 YT-DLP / INGESTION

Content Ingestion & Stream Monitoring

Monitors creator livestreams, Whop bounty targets, and source channels via yt-dlp. Supports direct URL uploads and Telegram bot automated intake.

STAGE 02 WHISPER AI

Millisecond Speech-to-Text Transcription

Executes local OpenAI Whisper / faster-whisper inference to extract verbatim transcripts with precise word-level start and end timestamps.

STAGE 03 GEMINI FLASH / LLM

AI Viral Hook Scoring & Truncation

Analyzes candidate segments using Google Gemini Flash, evaluating narrative arc, emotional spikes, and pacing to produce viral probability scores.

STAGE 04 YOLOV8-FACE

Computer Vision 9:16 Smart Face Tracking

Deploys YOLOv8 face detection neural weights (yolov8n-face.pt) to track active speakers and dynamically frame wide horizontal footage into 9:16 vertical shorts.

STAGE 05 REMOTION & FFMPEG

Dynamic Typography & Layout Assembly

Renders frame-accurate kinetic animated subtitles via Remotion React compositions and performs split-screen compositing and audio ducking with FFmpeg.

STAGE 06 YOUTUBE API / PLAYWRIGHT

Multi-Channel Isolated Dispatching

Dispatches videos to YouTube Data API v3 and social accounts using isolated Chrome profile sandboxes, sequential anti-flag delays, and residential proxy guards.

STAGE 07 SSE TELEMETRY

Telemetry Streaming & View Auditing

Streams real-time terminal output to the dashboard via Server-Sent Events (SSE) and performs on-demand yt-dlp telemetry sweeps of the last 3 published videos per node.

// OPERATIONAL CAPABILITIES

Engineered For Fleet Reliability

Physical Disk Profile Isolation

Each of the 30 creator fleet nodes operates inside its own dedicated browser profile directory (uploader_profiles/profile_N), guaranteeing zero cookie collisions and zero cross-account session contamination.

Residential SOCKS5 Proxy Gateway

Avoids social platform bot blacklists through an integrated home WiFi / residential SOCKS5 proxy tunnel, masking automated uploads behind genuine residential IP infrastructure.

Remote Mobile noVNC Cloud Auth

Enables operators to approve Google 2FA challenges and solve platform security prompts on the cloud server directly from a smartphone screen via browser-streamed noVNC display.

Sequential Human Jitter Scheduler

Dispatches videos using algorithmic randomized intervals (20–30 minute human jitter) preventing velocity-based anti-spam triggers across target platforms.
