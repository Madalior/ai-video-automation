# AI Legend - Quick Start

## Installation

```bash
# 1. Install Python dependencies
pip install rich pyperclip

# 2. Start Genkit service
cd genkit-service
go run main.go
```

## Usage

```bash
python ai_legend.py "your goal here"
```

## Examples

```bash
# Fix a bug
python ai_legend.py "fix the parallel director bug"

# Add a feature
python ai_legend.py "add batch processing to info pipeline"

# Optimize code
python ai_legend.py "optimize video generation performance"
```

## What You Get

✨ **Optimized Prompt** - Context-rich, structured prompt for Antigravity  
📋 **Auto-Copy** - Prompt copied to clipboard automatically  
💾 **History** - Saved to `prompts/history/` for reference  
🎯 **Smart Context** - Relevant files, errors, and project structure analyzed

## Workflow

1. Run AI Legend with your goal
2. Review the generated prompt (displayed in terminal)
3. Paste to Antigravity (already in clipboard)
4. Get better, faster results!

For detailed documentation, see [ai_legend_usage.md](./ai_legend_usage.md)
